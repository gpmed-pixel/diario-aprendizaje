# Diario de aprendizaje
Este es mi primer repositorio para aprender y emprender el camino del conocimiento. Me servirá en el futuro como ejemplo de superación personal.

## Estructura
- `diario.md` → Resumen diario donde informo lo aprendido, lo que generó dudas y las tareas siguientes.
- `apuntes/` → Apuntes de los conocimientos necesarios para la realización de las tareas.

## Formato del diario
-Aprendí: Aquí se anota todo lo aprendido de manera resumida.
-No entendí: Aquí anoto las dudas y los errores para que sean corregidos.
-Mañana: Aquí anoto las tareas que se deberán realizar en la siguiente sesión.
